# Breast-Cancer# **Breast Cancer Detection Project**

This project is a **Breast Cancer Detector** using Python and TensorFlow.  
It allows you to classify breast cancer images as **benign** or **malignant** using a deep learning model.

---

## **Requirements**

The project depends on the following Python packages:

- **tensorflow** (2.19.0)  
- **opencv-python** (4.12.0.88)  
- **scikit-learn** (1.6.1)  
- **matplotlib** (3.10.0)  
- **split-folders** (0.5.1)  

Other dependencies are automatically installed with TensorFlow, including **keras**, **numpy**, **protobuf**, **grpcio**, **tensorboard**, and **termcolor**.
